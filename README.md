# ร้านข้าวปั้นริมคลอง

เกมทำซูชิสำหรับเด็ก เล่นได้ในเบราว์เซอร์ทั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์ ไม่ต้องติดตั้งอะไร

## วิธีเล่น

1. แตะวัตถุดิบในตู้เย็นเพื่อวางลงบนเขียง
2. เลือกเครื่องมือแล้วแตะที่อาหาร: หั่น · ทอด · ปั้น (เฉพาะข้าว) · แต่ง · ทิ้ง
3. กด **ม้วน** เพื่อรวมทุกอย่างบนเขียงเป็นซูชิม้วน
4. กด **เสิร์ฟ!** แล้วดูว่าลูกค้าชอบไหม
5. กด **ลูกค้าคนต่อไป** เพื่อเปลี่ยนลูกค้า

ลูกค้ามี 4 ตัว แต่ละตัวชอบอาหารไม่เหมือนกัน คำทักทายของแต่ละตัวมีคำใบ้ซ่อนอยู่ เกมไม่มีคะแนนและไม่จับเวลา

## เปิดเล่นบนเครื่อง

ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ ถ้าไม่ต่อเกมยังเล่นได้ แต่ใช้ฟอนต์ของเครื่องแทน)

## เปิดเป็นเว็บด้วย GitHub Pages

1. ไปที่ **Settings → Pages** ของ repository นี้
2. ที่ **Source** เลือก **Deploy from a branch**
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที ลิงก์จะขึ้นในหน้าเดียวกัน ในรูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`
